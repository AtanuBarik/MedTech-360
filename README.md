# MedTech 360

MedTech 360 is an Evalueserve-themed prototype intelligence platform for MedTech clients. It combines Competitive Intelligence and Primary Market Research workflows across six domains:

- Autoimmunity & Allergy
- Diabetes & Blood Glucose Monitoring
- Ophthalmology & Eye Health
- Orthopedics & Sports Medicine
- Advanced Wound Management
- Clinical Laboratory Services

## Prototype flow

1. Login page with Enterprise SSO and username/password options
2. Role selection: Hub Owner, Contributor, Viewer
3. Interactive MedTech 360 dashboard with domain switching, CI modules, PMR modules, signals, competitor benchmarking, voice-of-customer visualization, and a prototype intelligence assistant

## Access locally

Download or clone this repository and open `index.html` directly in a modern browser. No Python, Node.js, package installation, or local server is required.

## Publish with GitHub Pages

1. Open the repository in GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Click **Save**.
6. After GitHub finishes publishing, the site should be available at:
   `https://atanubarik.github.io/MedTech-360/`

## Important prototype note

All dashboard counts, benchmark scores, signal intensities, and similar numeric values are illustrative placeholders for demo purposes and are not client research findings.
